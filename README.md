# Robotic Arm Digital Twin & Control System

## Project Overview
A robotic arm project combining ESP32-based servo control and 3D simulation using Python and PyBullet.

## Technologies
- Python and PyBullet
- ESP32 and C/C++
- PCA9685 Servo Controller
- URDF Robot Modeling

## Project Goals
- Develop robotic arm control
- Simulate robotic movements in 3D
- Explore forward and inverse kinematics
- Integrate physical hardware with simulation
